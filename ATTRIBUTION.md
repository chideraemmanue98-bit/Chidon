## 3. Typography & Fonts

All font systems are referenced dynamically from official Google Web Font channels under non-commercial or public domain distributions:

*   **Inter**: Utilized for standard UI labels, buttons, and responsive inputs. Styled with neutral weights under the **SIL Open Font License (OFL)**.
*   **JetBrains Mono**: Utilized for technical log outputs, command status nodes, metadata, and JSON layouts. Distributed under **SIL Open Font License 1.1 (OFL)**.

## 4. Legal Compliance Confirmation

As of June 11, 2026, **CHIDON IQ** represents a 100% compliant, custom codebase:
1.  **No Copyrighted Media**: Zero proprietary logos, trademarked layouts, or non-licensed templates are contained within `/public/` or `src/`.
2.  **Permissive dependencies**: All custom packages specified inside `package.json` are standard components distributed on public npm registries under modern permissive standards.
3.  **Original algorithms**: All layout patterns, grid styles, state syncing hooks, and responsive micro-interactions are written directly for this applet’s custom viewport.
